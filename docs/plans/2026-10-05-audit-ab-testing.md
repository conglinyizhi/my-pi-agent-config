# 审核 A/B 测试（设计稿）

> 位置：在审核流 SDK **之前**做。它回答「换套审核方式会不会更准、更贵、更慢」，
> SDK 回答「改起来方不方便」。前者是后者的前提：先能量出差别，再谈重构。
>
> 两者独立：A/B 不依赖 SDK 就能落地；SDK 做完后 A/B 继续可用（那时它可以变成图上的一个影子节点）。

## 1. 要回答的问题

1. 换模型（对话模型 ↔ 角色模型）、换提示词、换维度阈值，**判定结果差多少**
2. 差的方向：变松（把原判 risky/dangerous 的判成 safe，危险方向）还是变严（把原是 safe 的拦下来，吵人方向）
3. 代价：延迟与调用次数差多少
4. 哪些输入上两者分歧——分歧样本比统计数字有用得多

## 2. 两种跑法

### 影子模式（在线）

- 主链照旧判定并决定放不放行；**影子链的结果只记录，不参与任何决定**
- 只对已经要弹闸门的事件跑影子（人本来就在看，多花的那次调用不额外占路）
- 按比例抽样（默认 10%，设置里可调）
- 影子失败一律吞掉并记一笔：**任何情况下不许挡住主链**，这是硬约束

### 重放模式（离线）

- 用导出的 .ts 夹具重跑两套配置，输入完全相同
- 适合调参：改完阈值不用等真实流量，几十条夹具几秒出结果
- 夹具带送审文本，属敏感内容：仓库里只放脱敏样本，本地夹具放状态目录

## 3. 配置形态

变体是一份具名配置，与现有 [sandbox-llm-review] 同形（模型、后端、提示词、维度阈值）：

```toml
[audit-ab]
enabled = true
mode = "shadow"            # shadow 在线影子 / replay 只离线 / off
sample_rate = 0.1           # 只对要弹闸门的事件抽样
max_shadow_calls_per_hour = 60

[audit-ab.variants.strict-prompt]
backend = "chain"
chat_model = "..."
prompt_file = "prompts/review-strict.md"
```

主链配置一行不动：**A/B 不改判定，只加观察**。

## 4. 记录什么

一条记录 = 一次事件的两侧结论：

```
事件指纹（命令/脚本摘要 + 场景）/ 时间 / 抽样标记
主链：verdict、理由、耗时、模型、是否命中缓存
影子：同形的一套
分歧方向：danger-side / noisy-side / none
（可选）节点级轨迹，前提是那一层已经存在
```

落盘：状态目录（不进仓），按天分文件，带体积上限与自动清理，默认留 30 天。
送审文本按需截断保存，默认不存全文。

## 5. 报告

`scripts/audit-ab-report.ts` 打印四块：

1. **一致性矩阵**：主链 × 影子的 4×4 计数（safe / risky / dangerous / error）
2. **危险方向**：影子判 safe 而主链判 risky/dangerous 的条数——这个数不为零就得逐条看
3. **代价**：两侧的 P50/P95 延迟与调用次数
4. **分歧样本**：按方向列出前 N 条，附一条命令把那次输入固化成 .ts 夹具

## 6. 硬约束

1. 影子永不参与判定：不能放行、不能拦截、不能改附言
2. 影子的任何失败（超时、报错、模型抽风）都不许影响主链的延迟与结论
3. 影子不得携带写权限或沙箱放宽
4. 抽样率与调用上限可关停，一键回到没有这个功能的状态
5. 分歧样本按敏感内容对待：默认不落全文、不进仓

## 7. 分期

| 期 | 内容 | 完成标志 |
|---|---|---|
| 1 | 影子跑通：变体配置 + 抽样 + 记录 + 失败隔离 | 一次真实审核留下两侧结论，主链行为零变化 |
| 2 | 报告脚本：一致性矩阵 + 危险方向 + 代价 | 能回答「这套配置值不值得换」 |
| 3 | 重放模式：夹具导出/导入 + 离线对比 | 改阈值不用等流量 |
| 4 | （可选）报告进窗口 | 只有前 3 期天天在用才做 |

## 8. 与 SDK 的关系

- A/B 先做且独立：它只加一条观察支路，不动判定主干
- SDK 做完后 A/B 变成图上的影子节点，期望零改动迁移
- **顺序不能反**：先重构再测量，会分不清「变准了」是因为新模型还是因为重构本身

## 9. 待你拍板

1. 抽样率默认 10% 还是更低（影子真花钱）
2. 记录保留 30 天、不存送审全文，够不够
3. 第一期要不要就把「危险方向为零」做成断言式检查（跑报告时非零则退出码非零）
