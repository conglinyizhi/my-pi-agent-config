# Aesthetics — 界面与空间

> 本地薄技能（`skills/clyzhi`）。吸收 zhichi-shanlin 的空间动作核，并与 tiangong 的日常设计用法对齐。
> 上游正文：`skill-repo/tiangong`（MIT · WUJI Labs）。本文件只进 pi 配置仓，不推远程。
>
> **读法**：术语后括号是白话。**按白话做**；典源名只是标签，不是要你画山水、谈气功。

## 何时用

- UI/UX、配色、排版、品牌视觉、设计评审
- 抱怨「没灵魂 / 不好看 / 差点意思」
- 画面太平、太满、闷、挤，用户不知道下一步往哪走
- 多屏/多步流程（onboarding、引导、叙事）缺层次，像一堆卡片平铺

**分工**：文学中文 → `bibuzaohua`；本技能只管「看起来顺眼 / 用得进去」。重型框架再读 `tiangong`。

## 易误读对照（先看这表）

| 词 | 在本技能里指 | 不是指 |
|----|--------------|--------|
| 气韵 | 整体气质是否统一、是否「活」——有主情绪/主节奏 | 玄学里的「气」、算命、装神 |
| 骨法 | 骨架：层级、对齐、字重、分隔是否撑得住 | 书法笔法课、骨骼解剖 |
| 赋彩 | 上色要分角色：功能色/品牌色/背景色各干各的 | 必须用中国传统色、工笔设色教程 |
| 经营位置 | 排版布局：谁当主角、元素放哪 | 经营管理、开店选址 |
| 大巧若拙 | 高级往往显得朴素；能减则减 | 故意做丑、假土、放弃工艺 |
| 三远 | 页面上的三种「深」：上下 / 前后 / 左右 | 必须画成山水、写生术语考试 |
| 高远 | 上下分层（顶/中/底，或标题压细节） | 一定要仰视高山的感觉 |
| 深远 | 前后纵深（遮挡、叠层、步进、近大远小） | 一定要透视灭点画法 |
| 平远 | 左右延展（横滑、时间线、宽画布） | 画面必须「平淡无奇」 |
| 可望 | 只能看，进不去（海报级） | 道德上的「可望而不可即」抒情 |
| 可行 | 知道从哪进、第一步点哪 | 徒步路线规划 |
| 可游 | 愿意顺着路径逛下去 | 旅游文案 |
| 可居 | 还想回来停住（有归属/常用） | 真的居住、房产 |
| 留白 | 有意留下的空：呼吸、动线、休息区 | 懒得设计、没内容、残缺 |
| 境 | 用起来的整体感受（顺不顺、闷不闷） | 修仙境界、意境散文 |

## 快速动作

### A. 视觉

1. **气韵**（整体气质统一吗？像活的还是零件堆的？）  
   有没有一条主情绪、主节奏？
2. **骨法**（骨架硬不硬？）  
   层级、对齐、字重、分隔够不够？骨架软就先补结构，别先堆装饰、插画、渐变。
3. **赋彩**（颜色有没有分工？）  
   功能色（成功/警告/链接）、品牌色、背景/中性色各干各的；别做成彩虹盘。
4. **经营位置**（谁当主角？）  
   主次能不能一眼看出来？焦点优先只留一个。
5. **大巧若拙 / 节制**（还能再减一档吗？）  
   能减就减：素一点、准一点、空一点、别吵。减完更稳 = 原来过装饰了。

### B. 空间

1. **三远**（至少制造一种「深」，别整页平铺）  
   - **高远** = 上下分层  
   - **深远** = 前后纵深（叠层、遮挡、步进）  
   - **平远** = 左右延展（横滑、时间线）  
   一页里有一种就比纯网格强；不是要你三远齐上。
2. **可望 → 可行 → 可游 → 可居**（待得住的四级，用来诊断，不是文案辞藻）  
   - 可望：只能看  
   - 可行：知道入口  
   - 可游：路径愿意逛  
   - 可居：还想回来  
   自问：用户能不能走进去，并愿意停？
3. **留白**（空是功能，不是偷懒）  
   满 ≠ 丰富。空白处承担呼吸和动线；乱空（没对齐的缝）不算留白。
4. **先看见再经营**（先动线，后摆件）  
   改布局前说清：人从哪进、在哪停、往哪走。说不清就别先调间距。

## 评审清单

- [ ] 主焦点唯一，次要信息退让
- [ ] 至少一种纵深（层级 / 阴影 / 步进 / 前后景）
- [ ] 有明确动线，不是无序色块
- [ ] 留白够用且整齐，不靠描边硬撑
- [ ] 减一档装饰后是否更稳？若是，减

## 输出习惯

短评：问题一句 → 改法一句 → 可选前后对比。  
长方案才展开配色 / 字号 / 栅格。  
对外说话优先用白话（骨架、层次、动线、留白）；典源词可作标签，别当唯一输出语言。
