# 辩证加核 — 叩两端 · 临界 · 时中

> 由 `brain-bootloader` 在**两难 / 单值结论 / 趋势判断**时加载。  
> 读法：括号内白话；下表优先于望文生义。

## 易误读对照

| 词 | 在本文件里指 | 不是指 |
|----|--------------|--------|
| 叩两端 | 点名当前决策的真对立轴 A↔B，把两极推到头问清楚 | 固定写「极限成功 vs 极限失败」；也不是算命 |
| 两端 | 这件事上真正拉扯的一对极点（随问题变） | 永远等于「好 vs 坏」「正例 vs 反例」 |
| 张力轴 | 我们在权衡的那条线（如快↔稳） | 物理学公式、情绪张力散文 |
| 推到头 | 若只顾这一极，得到什么、死在哪（可检验） | 鸡汤巅峰或末日寓言 |
| 标临界 / 临界 | 再往前就会翻面的**可观察**条件 | 玄学气数、命运转折点 |
| 物极必反 | 偏到过头会换来反面后果；要写出触发信号 | 宿命论、劝你认命 |
| 时中 | **现在**这样最合适；可写「出现 X 就改偏」 | 永远站中间、各打五十大板、中庸套话 |
| 辩证 | 强制看对立面与条件，再下判断 | 诡辩、和稀泥、上纲上线 |

## 何时用

预检中出现：**两难 / 只给一个结论 / 要判断趋势**。  
强制看对立面，别只报喜。

## 1. 叩两端（把真对立的两极问到底）

**两端 ≠ 固定模板「极限成功 vs 极限失败」。**  
两端 = **当前这件事上真正拉扯着的那一对对立面**——随问题变。

### 操作四步

1. **点名张力轴**：在权衡的是 A↔B？写出来。轴没点名 = 后面多半是假两端。
2. **把 A 推到头**：若只顾 A，得到什么、死在哪？（可检验，别写鸡汤）
3. **把 B 推到头**：若只顾 B，得到什么、死在哪？
4. **再谈落点**：见下「时中」。

「推到头」可以像极限案例，但极限的是**这根轴上的两极**，不是宇宙级成/败童话。

### 常见轴（举例，不是凑数清单）

| 问题类型 | 常见两端 | 说明 |
|----------|----------|------|
| 要不要上新方案 | 收益 ↔ 成本/风险 | 不是「全成 vs 全败」 |
| 架构取舍 | 简单/快交付 ↔ 稳/可扩展 | 同一资源上的真对立 |
| 产品策略 | 当下现金流 ↔ 长期口碑 | |
| 性能优化 | 体验/延迟 ↔ 复杂度/钱 | |
| 信息与控制 | 自己可控 ↔ 依赖外部 | |
| 呈现 | 显（用户看得见）↔ 隐（后台/长期） | |

**好坏轴**（最好能多好 / 最差能多差）只是一种轴：适合风险、容量、失败模式。  
很多决策的轴根本不是好坏，硬写成正反故事 = 误会。

### 禁止的假两端

- 只写「好处三条、坏处三条」对称凑数，轴都没点名
- 假对立：同一面的两种措辞（「更快」vs「更高效」）
- 用极限正反代替结构思考：成功学童话 / 末日寓言，没有可检验条件
- 只报喜或只报忧，另一端空着就收工

**判据**：只写一面就收工 = 没做完。

## 2. 标临界（写出「再往前就会翻面」的信号）

- 现状之外补一句「正往哪走」。
- **物极必反**在这里只表示：偏到过头会换来反面后果——必须写成**可观察条件**，不是认命。  
  例：再堆三个特性维护成本会爆；延迟再降 10ms 要换存储；补贴再高一点单位经济模型翻脸。

## 3. 时中（按**当下**选恰当，不是永远站中间）

- 落点：「**现在**这样最合适」。
- 最好带触发器：「若出现 X 信号，则改偏 Y」。
- **不是**各打五十大板，**不是**和稀泥式中庸套话。

## 边界

不搞占卜、不预测命运、不为医疗/投资/法律拍板。
